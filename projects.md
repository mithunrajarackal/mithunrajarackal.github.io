### Cerenode Mapper

ETL tool for ingesting and mapping heterogeneous data to RDF graph databases

**Description:** Developed an ETL (Extract, Transform, Load) pipeline for processing heterogeneous data sources and mapping them to RDF graph databases for semantic data storage and querying.

**Tech Stack:** Scala, Akka, AngularJS

**Key Features:**
- Scalable data ingestion using Akka actors
- RDF graph database integration
- Real-time data transformation and mapping
- RESTful API for data access
